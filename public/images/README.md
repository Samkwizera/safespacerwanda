# Image sources

The SafeSpace Rwanda logo was supplied by the project owner on 26 October 2026. The website uses `safespacerwanda-logo-transparent.png`, a background-free extraction that preserves the original orange artwork.

The current community photos are temporary stock images from Pexels and are free to use under the Pexels license. Source URLs and photographer credits are recorded next to each image in `src/content/images.ts`. Replace them with consented SafeSpace Rwanda photography when it becomes available.
